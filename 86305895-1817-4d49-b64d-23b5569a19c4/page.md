## Памятка: порядок действий

1. Сначала выполняем действия **в скобках**.
2. Затем **умножение и деление** — по порядку слева направо.
3. Потом **сложение и вычитание** — по порядку слева направо.
4. Помни: a · 0 = 0, 0 : a = 0, a · 1 = a, a : 1 = a.

Совет: перед вычислением надпиши над каждым знаком номер действия.
